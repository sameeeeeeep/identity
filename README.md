# identity

Identity — compose an AI persona and publish it as context, on your own Claude

A [Switchboard](https://thelastprompt.ai/switchboard/) wrapp. Live features need the Switchboard
extension + the local daemon, paired. Without them the page renders standalone and model calls
degrade to an honest error.

Built from `examples/apps` in [sameeeeeeep/switchboard](https://github.com/sameeeeeeep/switchboard) —
this repo is the built artifact, not source.
